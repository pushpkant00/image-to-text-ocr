How it works

Three ways to grab text — all of them stay on your machine.

  1. 1

    Select, right-click, or paste

    Press Ctrl+Shift+X and drag over any area, right-click an image and choose Extract text from this image, or paste a screenshot with Ctrl+V.

  2. 2

    OCR runs on your device

    Tesseract.js recognizes the text locally in an offscreen document. English works fully offline out of the box; other languages download once and cache.

  3. 3

    Preview or copy the result

    A compact result card appears with the text one click behind Preview — resizable — and Copy puts it straight into your clipboard. Nothing is copied until you ask.

Everything you need, nothing you don't

Built as a fast, private utility — not a service you have to trust.

  • Private by design

    Images are captured and read in the browser. No servers, no accounts, no telemetry — your text never leaves the device unless you choose to sync.

  • 7 languages

    English (offline by default), Hindi, Spanish, French, German, Japanese, and Simplified Chinese. Pick the language per capture or set it as default.

  • Works offline

    After the first run, English recognition is completely offline. Capture text on a plane, behind a firewall, or on a locked-down network.

  • Searchable history

    Every result lands in a side panel you can search, filter by language, and clear. Confidence scores tell you how sure the recognition was.

  • Optional cloud sync

    Create an account if you want history on all your machines. Sync is opt-in, merge-based, and can be cleared at any time.

  • Keyboard-first

    Ctrl+Shift+X starts a selection anywhere, Esc cancels, Ctrl+V OCRs a pasted screenshot from the popup.

Install in under a minute

The extension isn't in the Web Store yet — load it unpacked, Chrome-Extensions-style.

Get it free on GitHub
  1. 1

    Get the files

    Download or clone the repository from GitHub, then run npm install, npm run setup, and npm run build — or grab a ready-made release if available.

  2. 2

    Open the extensions page

    Visit chrome://extensions and turn on Developer mode (toggle, top-right).

  3. 3

    Load unpacked

    Click Load unpacked and select the project's dist folder. The icon appears in your toolbar.

  4. 4

    Extract your first text

    Press Ctrl+Shift+X on any page, drag over some text, and copy the result.

Your images stay yours

Most OCR tools upload a screenshot of your screen to a server. This one doesn't — recognition happens inside your browser, in an offscreen document, with the language model stored locally.

  • No accounts required — every core feature works without signing in.
  • Screenshots are processed locally and discarded after OCR.
  • Cloud sync is opt-in: create an account only if you want cross-device history.
  • Fully open source — read the code and verify every claim yourself.

FAQ

Does it need an internet connection?

English recognition is fully offline after setup. Other languages download their model once (about 3 MB) and are cached for offline use afterwards.

Where do my images and text go?

Nowhere. Capture, cropping, and OCR all happen on your device. The only optional network traffic is the one-time language model download and account sync, if you turn it on.

Which languages are supported?

English, Hindi, Spanish, French, German, Japanese, and Simplified Chinese — switchable per capture or as your default in the popup.

Is it really free?

Yes. It's MIT-licensed and open source — no trials, no pro tier, no ads. Issues and pull requests are welcome on GitHub.

How accurate is it?

It depends on image quality, but every result shows its confidence score so you know when to double-check. Clean screenshots of printed text work best.
